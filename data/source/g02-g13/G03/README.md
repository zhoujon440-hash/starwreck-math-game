《星骸拾荒者》G03齿轮荒原
Unity数据级制作脚本 V2.1

主角：星宇｜第二章开发数据包｜HOPA实施版

# 一、实施范围

本包将G03剧情母本转化为可供Unity加载的场景、热点、找物、背包、对话、状态机、提示、存档、变量和资产映射数据。剧情主线不重写，重点消除旧版追逐/Boss逻辑并落实HOPA交互。

# 二、本章核心机制

MECH-004真实需求表：区分平均分配与按实际需求分配。

MECH-005订单欺骗：对齐原稿、改写层、印章时间和货箱标签。

MECH-006传送带逆行：调整方向、速度和分流门。

MECH-007公开分配会：先满足最低保障，再安排生产与储备。

# 三、管理员权限解除

饕餮不进入战斗。玩家依次提交真实需求表、订单取证、物流修复和公开分配方案，最后断开饥饿控制器。各权限独立保存，失败只重置当前节点。

# 四、防卡死规则

关键货箱和证据错误使用不消耗。

腹仓闭合失败退回上一安全节点，已打开分流门保留。

传送带过速触发保护停机，只撤销最近一次带速调整。

公开分配不满足急救、供暖和储备阈值时禁止提交。

找物完成后不刷新关键物；离开小游戏保留已确认步骤。

player_name固定为星宇，禁止旧名写入。

# 五、开发验收

42个热点可由数据表加载。

5个找物场景可正确重进。

20个背包道具无重复取得或错误消耗。

MECH-004—007和UI-016—019、062—063调用正确。

管理员阶段无血量、攻击、敌人锁定。

章节完成后解锁G04镜面沙海。
