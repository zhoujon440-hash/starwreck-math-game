《星骸拾荒者》G05刻度冰原
Unity数据级制作脚本 V2.1

主角：星宇｜第四章开发数据包｜HOPA实施版

# 一、实施范围

本包把G05剧情母本转换为Unity可加载的数据规格，覆盖两条高度线、动态标准、量杯上涨、第一次冰桥失败、薄冰撤离、滑轨桥与冰夷权限解除。

# 二、核心机制

MECH-012双高度校准：排除镜像与单位错误。

MECH-013量杯上涨：最低保障、容量与安全余量。

MECH-014误差带测量：多次读数、当前值、误差范围与复测周期。

MECH-015薄冰安全路线：厚度、压力、步距与回退保护。

# 三、剧情性失败

星宇在SCN-G05-03必须因单次读数后立即铺桥导致桥头错位。该失败不允许被跳过，但不造成整章重置；桥板损耗和角色反馈作为持久状态进入后续场景。

# 四、管理员权限解除

冰夷不进入战斗。玩家依次提交高度校准、供水恢复、误差带测量和安全路线结果，最后维修冰龙风切控制器。

# 五、防卡死规则

关键测量工具错误使用不消耗。

异常读数保留，不允许自动覆盖。

薄冰路线失败只退回上一安全节点。

量杯站低于最低保障时禁止提交。

动态报告必须同时包含当前值、误差范围与复测周期。

player_name固定为星宇。

# 六、开发验收

35个热点可由数据表加载。

5个找物场景重进不刷新关键物。

20个背包道具来源和用途完整。

MECH-012—015与UI-024—027、066—067调用正确。

管理员阶段无攻击、血量与敌人锁定。

章节完成后解锁G06分片群岛。
