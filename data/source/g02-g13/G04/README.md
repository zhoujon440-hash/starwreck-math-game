《星骸拾荒者》G04镜面沙海
Unity数据级制作脚本 V2.1

主角：星宇｜第三章开发数据包｜HOPA实施版

# 一、实施范围

本包把G04剧情母本转化为Unity可加载的数据级制作规格，覆盖场景、热点、找物、背包、对话、状态机、提示、存档、程序变量以及MECH/DANGER/UI映射。

# 二、本章核心机制

MECH-008现实/镜像双层坐标：区分坐标所属层并完成转换。

MECH-009记忆耐久：以来源、时间与旁证验证记忆后再固定。

MECH-010反向输入机关：先单步测试，再提交完整序列。

MECH-011欺骗预测：从历史案例提取共同特征并验证真实入口。

# 三、管理员权限解除

九尾狐不进入战斗。玩家依次提交真实坐标、两组固定记忆、反向规则与已验证入口预测，最后维修九尾镜核。每项权限独立保存，失败只重置当前节点。

# 四、防卡死规则

记忆铆钉只有在验证完整时才能消耗。

验证标记错误使用不消耗。

反向门阵错误输入只撤销最后一步。

镜片风暴失败退回最近安全台，已安装反光布保留。

档案矛盾片段必须保留，不允许系统自动删除。

player_name固定为星宇，禁止旧名写入。

# 五、开发验收

36个热点可由数据表加载。

5个找物场景重进不刷新关键物。

18个背包道具无错误消耗。

MECH-008—011和UI-020—023、064—065调用正确。

管理员阶段无血量、攻击和敌人锁定。

章节完成后解锁G05刻度冰原。
