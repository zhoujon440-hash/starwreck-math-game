# G01 Demo 试玩说明

版本：`G01-DEMO-0.1.0`

公开试玩地址：<https://zhoujon440-hash.github.io/starwreck-math-game/>

这是 G01 序章《拾光号：坠落之前》的八场连续 HTML5 / PWA 试玩版。流程从
`SCN-G01-00` 开始，到 `SCN-G01-07` 完成后停在“旧屏幕谷外缘”只读交接画面。
交接画面没有 G02 热点、找物、背包、谜题或剧情流程。

## 开始试玩

1. 打开试玩地址，选择“开始新游戏”。
2. 在场景中点击画面里的真实物件和设施；正式界面不会显示调试圆点。
3. 找到的关键物会进入底部背包。桌面端可拖拽到对应设施，也可先选择道具再点击目标。
4. 遇到机关时打开局部近景完成拼图、连线、分析或校准。
5. 提示按钮按“方向 → 区域 → 完成一步”三级递进。
6. 进度会自动保存在当前浏览器。主菜单提供继续游戏、开始新游戏并清除存档和试玩说明。

## 八场流程

1. `SCN-G01-00`：拾光号熄灯。
2. `SCN-G01-01`：找回七码。
3. `SCN-G01-02`：船上第一张任务单。
4. `SCN-G01-03`：漏气的货舱。
5. `SCN-G01-04`：星图缺口。
6. `SCN-G01-05`：垃圾雨航线。
7. `SCN-G01-06`：锈环星求救信号。
8. `SCN-G01-07`：坠落之前。

正常人工观察、阅读对白并完成全部互动约需 20—30 分钟。自动化全流程用于回归验证，
不会在正式界面提供跳场景或测试菜单。

## PWA 与离线使用

首次联网完整打开后，可使用浏览器的“安装应用”功能。Service Worker 会缓存生产构建；
安装完成或页面已被接管后，即使离线刷新也能继续游戏。本地存档只保存在当前浏览器，
清除站点数据会同时删除进度。

## 本地运行

```bash
npm ci
npm run dev
```

生产验证与打包：

```bash
npm run validate:g01-demo
npm run test:g01-demo
npm run test:e2e
npm run test:pwa
npm run package:g01-demo
```

ZIP 输出为 `release/starwreck-g01-demo-0.1.0.zip`，内容是以
`/starwreck-math-game/` 为部署根路径构建的静态站点。

## 结束状态

完整通关后仅写入：

- `g01_chapter_complete=true`
- `g01_handoff_to_g02=true`
- `world_star_core_count=0`

七码搜寻、分析、寻路在 `SCN-G01-06` 按正式顺序授权；瞬移、缩小、复制体继续保持锁定。
