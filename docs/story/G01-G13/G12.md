# 一、文档定位与重构边界

本文件将原《百工星环》星球策划与小说V3.1管理员事件，重新翻译为可操作、可失败、可选择并产生后果的游戏关卡。核心数学内容“综合预算、测量、材料分配、工序安排、空间装配、数据试验”不以独立答题界面出现，而是嵌入追逐、潜入、救援、工程、权限冲突解除和角色决定。管理员不会站在门口宣布试炼，玩家会先遭遇由其错误规则造成的星球危机，再逐步识别真正控制源。

# 二、关卡体验目标

| 维度 | 设计目标 | 禁止做法 |
| --- | --- | --- |
| 冒险感 | 先让玩家身处危机，再通过观察和工具理解规则。 | 管理员直接弹题，答对开门。 |

| 数学融合 | 把综合预算、测量、材料分配、工序安排、空间装配、数据试验变成环境规则和资源限制。 | 连续出现与剧情脱离的练习题。 |
| 权限冲突解除表达 | 干预控制器、环境或规则，不以伤害生命为唯一目标。 | 传统削血到零。 |
| 失败反馈 | 局部回退、装备冒烟、NPC吐槽、路线变化；保留已获得知识。 | 长时间黑屏或整章重置。 |
| 青少年层次 | 保留伦理选择、团队冲突与不确定后果。 | 把冲突简化成单一正确口号。 |

## 2.1 情绪曲线与存档

| 阶段 | 情绪 | 设计要求 |
| --- | --- | --- |
| 进入0—5分钟 | 奇观与失控 | 可立即移动并遭遇第一处危险 |
| 调查5—25分钟 | 困惑与争执 | 发现表面规则不能解释真实问题 |
| 探索25—60分钟 | 紧张与理解 | 进入危险区域取得关键证据/道具 |
| 反转60—85分钟 | 代价与选择 | 第一次方案失败或必须放弃某物 |
| 管理员85—110分钟 | 连续动作与团队协作 | 非削血式破局 |
| 结算110分钟后 | 余波与下一钩子 | 后果进入飞船状态 |

存档点放在：抵达后、关键装备试装后、危险区域入口、管理员前、管理员阶段中点、结算后。

退出后恢复到最近安全点；已阅读的证据、已看过的动画和已确认的路线不重复强制播放。

## 3.1 星宇与七码的固定表现规则

星宇每册至少一次因冲动制造可见后果，但不得反复犯同一种错误。

星宇的聪明表现为观察材料、结构与现场限制后临时组合，不是突然知道标准答案。

七码每册至少三次低级错误：一次纯笑点、一次制造麻烦、一次意外暴露系统漏洞。

七码错误必须具体说出来，例如单位、方向、顺序、小数点或安全扣位置，不能只写“系统出错”。

## 6.1 主线逻辑约束

任务不是线性跑点：至少两处允许玩家先调查不同区域，再汇合到同一关键事件。

关键道具必须有来源和运输过程；不能在过场后自动出现在背包。

管理员入口前必须让玩家理解控制源与管理员本体的区别。

通关后必须回到居民层面验证改变，而不是只播放星核动画。

## 12.1 任务触发逻辑

主线采用状态机而非单纯任务列表。每个场景至少包含“进入、观察、第一次尝试、失败/反转、取得证据、完成”六类状态；剧情对白根据玩家是否先做支线、是否救人、装备是否损坏读取条件。

## 12.2 软重置原则

保留已看证据、已打开捷径、已完成的永久节点。

恢复角色到安全位置，环境危险回到阶段起点。

消耗品返还到阶段开始值，剧情性永久损耗不返还。

连续失败两次后，七码提出问题式提示；三次后开放可选演示，不强制。

## A.2 章节标准可玩循环

场景进入：读取场景状态与自动存档，显示当前目标，不直接弹出完整答案。

调查阶段：玩家点击热点、阅读环境反馈、与角色对话并收集线索。

找物与背包：取得冻结道具；道具可查看、组合、拖拽或点选后作用于目标。

危险处理：先出现方向、节拍、裂纹、温度、阴影或结构变化等预兆，再开放安全操作窗口。

机制阶段：打开对应机制UI；允许撤销、重试、三级提示和独立小游戏跳过。

结果阶段：成功后替换场景状态、更新任务日志、证据板、地图节点和角色对话。

章节冲突：管理员不进入战斗；玩家以已验证证据、维修结果与权限条件解除封锁。

章节结算：展示世界改变、方法回顾、遗漏可选内容和下一章线索，不采用战斗评分。

## A.4 场景状态机

S0 初始：主要阻碍存在，关键热点按剧情开放。

S1 调查：至少一个环境线索和一个角色/设备线索被确认。

S2 道具准备：关键道具或组合件进入背包，错误使用不消耗。

S3 处理中：危险循环和机制UI激活，可暂停、退出并恢复。

S4 已解除：危险停止或进入安全状态，开放新路径。

S5 已修复：场景替换、人物站位和环境音发生变化。

S6 回访：章节完成后保留新对话、可选证据和世界改变。

## A.5 找物、提示与跳过规则

每个找物场景需单列必找物、可选物、干扰物、层级、取得后背包名称和用途。

一级提示只指向调查方向；二级提示缩小区域；三级提示标记目标或自动完成一步。

连续失败后允许降低时间压力、扩大安全窗口或高亮可操作对象。

跳过只针对独立小游戏；跳过后自动写入必要剧情变量并播放简短结果说明。

关键证据判断和结局选择不可由系统静默替玩家决定。

## A.6 存档与防卡死

进入新场景、获得关键道具、打开机制前、机制成功后、权限解除后和章节结算时自动存档。

加载时恢复背包、证据、热点完成状态、机制步骤、危险安全节点和地图开放状态。

任何关键道具消耗必须与场景状态更新同一事务完成；失败则回滚两者。

玩家离开未完成小游戏时保存已确认步骤；重入时显示继续或重新开始。

若检测到道具已消耗但目标未完成，自动恢复道具或直接同步目标状态。

## A.7 能力权限规则

瞬移：仅限已发现、已修复、已授权锚点；双锚点谜题必须先完成两端许可。

缩小：仅在明确标记的设备内部或微观找物场景使用。

复制体：仅用于同步开关、镜面或双位置机关，不进行独立探索。

七码搜寻：只缩小搜索区域，不直接给出答案。

分析：只连接已收集证据，不生成未取得信息。

寻路：只显示已探索和已开放节点。
