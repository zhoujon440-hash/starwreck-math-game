# Trial Game Feel Runtime Architecture

版本：`STARWRECK-TRIAL-0.4.0`

本轮没有新增剧情、正式场景或生成式美术，而是把已验收的 11 个场景和 11 种机制接入同一个正式游戏运行层。运行层只在已有正式场景原画上登记对象坐标、镜头焦点、设备操作面和完成后的世界状态，不把 CSS 图形当作正式美术。星图碎片继续直接使用已登记的正式透明运行时资产。

## 运行闭环

`GameStage` 以 16:9 百分比坐标承载背景、正式场景图层、可交互对象、世界效果和轻量 HUD。玩家点击场景中的设备本体后，`SceneCamera` 从 `scene` 进入 `focus` / `mechanic`；`in-world-mechanic` 与场景画布等大，控制件按设备百分比坐标直接覆盖到配电箱、导航托架、中控桌、管路、星图桌、航图、通讯台、舷窗、废弃屏幕、吊臂和档案墙。它不包含通用 header、说明面板、状态栏页脚、重置或“提交当前结构”按钮。成功后镜头进入 `success`，设备对象与世界效果切换为完成态，再自动退回 `scene`。

旋转、拖放和滑轨在每次动作后实时判定；正确位置即时吸附，错误位置即时弹回且不写入进度，全部条件满足时自动完成。确需确认的取样、锁定或电闸动作被表现为设备本体上的独立实体拨杆，不复用网页式提交按钮。正式主线 DOM 不再渲染全宽 Topbar，自动保存与工具入口由场景内轻量 HUD 和短时反馈承担。

背包拖拽由 `InteractionController` 统一反馈：指针或触控拖动时物品跟随；正确目标返回 `snap`，错误区域返回 `bounce`，错误使用不消费物品。领取物品和剧情解锁人物只显示小型非阻断提示，正式详情保留在背包或档案的玩家主动入口。

| 场景 | 设备本体 | 世界变化 | 独立机制 |
| --- | --- | --- | --- |
| SCN-G01-00 | 配电箱 | 舱灯和电路恢复 | 旋转电路接点 |

| SCN-G01-02 | 中控任务墙 | 维修依赖链写入 | 任务排序 |
| SCN-G01-03 | 货舱阀门板 | 压力恢复稳定 | 气流迷宫 |
| SCN-G01-04 | 星图桌 | 星图缺口吸附闭合 | 星图拼图 |
| SCN-G01-05 | 航线台 | 安全路线持续发光 | 路线规划 |
| SCN-G01-06 | 示波台 | 求救波形锁定 | 波形调谐 |

## 可访问性与验收

减弱动画开启时保留四种镜头状态和全部机制逻辑，但把镜头、吸附、世界效果的过渡时间降为零。`Trial Game Feel Gate` 会运行全部既有门禁、新增的 36 条正向规则、16 个负向破坏用例，以及 1366×768、1920×1080 两套真实浏览器操作；视频、trace 和每关 `scene-before / object-focus / interaction-in-world / world-after` 四阶段截图均从同一 HEAD 生成。电路、星图和吊臂另各生成一段真实鼠标操作视频。
