# 试用版视觉验收说明

版本：`STARWRECK-TRIAL-0.3.0`

CI在 `Trial Experience Gate` 中生成两套成对证据：

- `1366×768`
- `1920×1080`

每套除原有标题、故事、档案、设置、存档与G01→G02流程外，还覆盖十一种小游戏各自的初始、错误、部分完成、完成四态，共44张机制证据；另有启动前身份零泄露、自我介绍与任务发布、场景地图、回访、返回当前任务和浅色界面截图。Playwright同时保存视频和trace。

视觉验收点：

1. 两种分辨率均无横向滚动、遮挡或溢出。
2. 标题页先于场景出现，入口按钮真实可用。
3. 正式界面不显示schema、RUNTIME ID、切片、验收、门禁、测试或后续开发文字。
4. 人物与物品使用既有已登记运行时资产，不使用PR #5、第三方网页图、Emoji或设计总览板。
5. 1366×768仍可完整操作标题、引导、档案和设置。
6. 十一种小游戏的`mechanicType`不重复，错误操作不消耗关键物或回滚已确认步骤。
7. 人物卡只在对应角色被剧情正式揭示后出现。
8. 回访已解锁场景后刷新，主线任务和场景完成状态保持不变。
9. `qima_identity_revealed=false`时，可见正文以及ARIA、alt、title均不出现角色正式身份；`DLG-G01-0025`自我介绍开始后才显示并解锁人物卡。
10. 十一种输入分别为独立接点旋转、播放后记忆复现、卡片拖拽排序、分支气流迷宫、星图片拖拽旋转吸附、危险边路线图、三轴连续波形、双轴姿态平衡、三格脉冲滑杆、配重挂点拖放、二维借用档案配对。

## 正式源交付门禁

GitHub Actions和Pages不再请求Git LFS对象。十九项正式源与三项隔离legacy原件通过GitHub Release `source-baseline-mirror-v1`交付；仓库清单固定整包及22个条目的大小和SHA-256。每个需要正式源的工作流先运行`node scripts/restore-formal-source-mirror.mjs`，再执行原有来源、基线、角色和剧情校验；Pages只检出实际运行时资产。

CI产物名称将在工作流运行号后附加，最终READY评论提供直接链接。
