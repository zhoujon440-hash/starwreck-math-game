## P0阻断问题

### 1. 找到物件后，物件图像没有从场景中消失

当前领航舱和维修柜均使用一张静态合成背景图。找到物件时只删除透明热点按钮，背景图中的手灯、保险丝、扳手、手套和线号标签仍然存在。

这不满足：

- 维修柜、保险丝取走必须有可见变化；
- 找物对象被拾取后，场景画面必须同步变化；
- 不能出现“点击成功但物件仍留在画面”的伪状态变化。

修改要求：

- 将可拾取物从背景中拆为独立透明图层，或准备拾取前/拾取后状态图；
- `foundItemIds`变化后同步隐藏对应物件图层；
- 领航舱手灯和维修柜四个目标物均须验证；
- Playwright增加断言：拾取前物件可见，拾取后物件图层消失。

### 2. 存档解析无法强制保证G01星核数为0

`save.ts`中当前写法先设置`world_star_core_count: 0`，再展开`parsed.flags`，旧存档中的非零值可以覆盖0。

修改要求：

```ts
flags: {
  ...(parsed.flags ?? {}),
  world_star_core_count: 0,
}
```

并增加Vitest：载入`world_star_core_count=12`的旧存档后，结果必须被规范化为0。

### 3. 端到端测试没有验证真实拖拽

当前Playwright仅验证“选中背包道具后点击目标”，没有验证桌面鼠标拖拽，也没有验证触屏pointer拖拽。

修改要求：

- 至少增加一条Playwright桌面拖拽用例；
- 保留点击替代操作用例；
- 验证拖拽正确目标进入S4，拖拽错误目标不消耗保险丝。
