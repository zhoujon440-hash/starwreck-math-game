# G02垂直切片视觉验收索引

## 生成方式

`tests-e2e/g02-slice-01.spec.ts`在1366×768和1920×1080两个Playwright项目中执行同一
套真实浏览器流程，并开启视频和trace。G02 Vertical Slice Gate上传：

- `g02-slice-01-visual-acceptance-<run_number>`
- `starwreck-g02-slice-0.1.0-<run_number>`

每个分辨率包含44张截图：

1. G01→G02交接、SCN00正式开场对白和SCN00初始场景；
2. SCN00危险软失败、刷新后安全节点、波形控制初始/错误/部分/完成态；
3. SCN00方向、区域和“只校准一个控制量”的三级提示中间态；
4. SCN01初始态、阿铆对白、挂索后软失败、救援态和三类标签；
5. SCN01实体标签槽初始/错误/部分/完成态及三级提示中间态；
6. SCN02初始态、正式三级提示、HOS初始/部分拾取/刷新恢复/完成；
7. 第三级只安装一枚电源键、错误使用不消耗、两屏修复与软失败恢复；
8. 档案对白、完成态、任务与证据、对话历史、角色档案；
9. 四组能量信号安全区及刷新恢复。

- 三场都有S0—S6、三级提示和持久化自动存档；

- 封存脉冲通过可见波形、间隔/增益/取样窗控制完成，不显示答案按钮；
