# G01第一轮验收标准

## 验收对象

SCN-G01-00《拾光号熄灯》以及支撑该场景的通用HOPA基础框架。

## A. 视觉验收

- [ ] 场景不是纯色占位图。
- [ ] 不显示圆点、文字标签或调试框。
- [ ] 维修柜、配电盒、手灯和保险丝在画面中具有真实视觉位置。
- [ ] 维修柜开启、保险丝取走、照明恢复均有可见变化。
- [ ] HUD不遮挡关键交互区域。
- [ ] 1920×1080和1366×768截图均可读。

## B. 交互验收

- [ ] 玩家能调查配电盒。
- [ ] 玩家能打开维修柜局部特写。
- [ ] 找物不是按钮列表，而是画面内点击物件。
- [ ] 临时保险丝进入背包。
- [ ] 临时保险丝可拖拽或选中后用于照明槽。
- [ ] 错误使用不消耗保险丝。
- [ ] 正确使用后照明恢复并进入S5。
- [ ] 场景完成后可进入下一场景入口。

## C. 数据与存档验收

- [ ] 场景、热点、物品和对话使用稳定ID。
- [ ] 场景状态使用S0—S6。
- [ ] 存档包含schemaVersion。
- [ ] 读档后维修柜、保险丝、照明和背包状态一致。
- [ ] G01变量中world_star_core_count保持0。

## D. 测试验收

- [ ] Vitest全部通过。
- [ ] Playwright可自动完成SCN-G01-00。
- [ ] 构建成功。
- [ ] 浏览器控制台无错误。
- [ ] CI通过。

## E. 禁止项

发现以下任一项，PR直接要求修改：

- 可见圆点热点；
- 按钮网格找物；
- 纯文本网页冒充游戏；
- 使用道具后画面无变化；
- 关键物误消耗；
- 使用旧名“小砾”；
- 战斗、血条、攻击或伤害机制。

## 验收结论

由项目负责人填写：通过 / 有条件通过 / 不通过。
