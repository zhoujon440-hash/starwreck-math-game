# 美术方向与运行时资产制作基线

## 1. 视觉母版

人物与世界统一使用：

- 旧纸张档案式设计语言；
- 布偶、旧机械、毛毡、缝线、铆钉和磨损金属；
- 青蓝能量光；
- 氧化橙作为关键识别色；
- 明确修补痕迹和长期使用感；
- 非低幼、非玩具广告式光洁造型；
- 角色轮廓、职业工具、体型和材质必须可快速区分。

## 2. 人物设计事实源

`星骸拾荒者_人物形象设计全集_V2.1_补齐版`包含十二星球人物三视图板，统计口径为71/71人物身份、71/71三视图。

G02核心人物板包含：星宇、七码、织星婆婆、豆包、阿铆、小线球、狰。

## 3. 运行时资产与设计板的区别

设计板用于确认：

- 角色身份；
- 正/侧/背结构；
- 面部和屏幕表情；
- 服装、材质、颜色、工具和配件；
- 关键识别特征；
- 状态变化方向。

运行时资产需要另行制作：

- 对话头像；
- 半身立绘；
- 表情状态；
- 场景姿态；
- 局部手势；
- 透明背景切片；
- 遮挡和光影适配；
- 背包图标或通讯图标。

Codex不得把设计板直接裁一块当最终头像，也不得重新生成与三视图不一致的新角色。

## 4. 角色生产流程

1. 读取角色三视图和母版；
2. 输出角色特征锁定表；
3. 输出运行时资产清单；
4. 从冻结造型制作透明运行时图；
5. 对照三视图检查比例、材质、配色和配件；
6. 在1366×768和1920×1080界面中检查清晰度；
7. 负责人验收后才允许进入剧情接入。

## 5. 禁止项

- 不得自行改变年龄、体型、服装和职业；
- 不得改变星宇的纽扣眼/电子镜片眼、橙色识别色和修复者装备；
- 不得把七码改成人形机器人或普通无人机；
- 不得加入未在母版中的武器、战斗护甲或炫技结构；
- 不得用文字方框、emoji或临时字母代替正式头像；
- 不得把生成式美术的随机变化称为“角色升级”。

## 6. 场景与物件

- 场景正式图需要拆分热点、前景、人物、特效和状态替换层；
- 找物物件必须与环境材质、光照和透视一致；
- 道具正式包用于造型，不代表每件已有背包图标和场景使用状态；
- UI设计板用于布局和视觉规范，运行时组件需按屏幕比例重建；
- 机制、危险和FX设计必须转译为HOPA局部反馈，不得恢复战斗表达。
