# 《星骸拾荒者：十二星门》唯一事实源

状态：冻结基线｜后续开发必须先读取本目录。

## 1. 当前产品形态

当前正式开发形态为 **HTML5/PWA HOPA互动式图像解谜冒险游戏**。Unity资料仅作为历史结构化数据母本，不代表当前引擎方案，也不得据此把项目改回Unity。

核心循环：场景探索 → 不可见热点 → 找物/线索 → 背包 → 道具使用/拖拽 → 局部机关/小游戏 → 状态变化 → 剧情推进。

## 2. 版本优先级

发生冲突时按以下顺序执行：

1. G01—G13整合正式包 V3.0及其G01数据、G02边界修订；
2. G02—G13数据级制作脚本 V2.1；
3. G02—G13 HOPA实施脚本 V2.0；
4. HOPA玩法与技术架构冻结修正版 V1.0；
5. 美术正式包：人物V2.1、场景V1.0、道具V3.0、FX/MECH/DANGER/UI V2.0；
6. 更早V1.0小说稿、战斗稿、Unity技术稿仅归档，不得覆盖以上基线。

## 3. 全局冻结规则

- 主角固定为 **星宇**；任何旧名只允许出现在`archive/legacy/`。
- 搭档固定为 **七码**，编号`EDU-0077`。
- G01是独立序章，不计入十二星球，不增加星核。
- G02—G13为十二颗星球。
- G01结尾必须保持：
  - `g01_chapter_complete=true`
  - `g01_handoff_to_g02=true`
  - `world_star_core_count=0`
- 正式场景状态统一为S0—S6。
- 关键道具错误使用不消耗。
- 危险失败回到安全节点并保留正确进度。
- 管理员冲突通过证据核验、修复、对话和权限解除完成，不做Boss战。
- 禁止战斗、血量、伤害、敌人AI、技能树、自由移动、实时3D和大规模骨骼动画。
- 禁止可见圆点热点、按钮网格伪找物和纯色占位图作为正式交付。
