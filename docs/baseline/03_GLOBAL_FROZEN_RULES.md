# 全局冻结规则

## 世界与章节

- G01《拾光号：坠落之前》是独立序章，不属于十二星球。
- G02—G13依次为十二颗星球。
- G01结束时星核数量必须为0。
- 每章必须承接上一章留下的装备、资源、关系、飞船状态或记忆影响，避免成为互不关联的小游戏合集。

## 角色

- 主角固定为星宇。
- 七码固定编号EDU-0077。
- 旧名“小砾”只允许存在于历史归档源文件。
- 当前运行时、测试、当前文档和新美术文件名不得出现旧名。
- 人物造型必须来自V2.1冻结人物设计，不得由Codex自行重设计。

## 玩法

- 游戏为HTML5/PWA HOPA。
- 无战斗、血量、伤害、敌人AI、RPG技能树和自由移动。
- 管理员通过证据核验、对话、修复和权限解除恢复。
- 数学知识嵌入观察、分配、测量、连接、路线和工程机关，不做独立答题页。
- 关键道具错误使用不消耗。
- 危险失败返回安全节点，保留正确进度。

## 能力

- 瞬移：仅限已发现、修复、授权锚点。
- 缩小：仅限指定微缩场景。
- 复制体：仅用于同步开关和镜像机关。
- 七码搜寻：缩小范围，不指出答案。
- 七码分析：只分析已收集证据。
- 七码寻路：只显示已探索和已开放节点。
- G01只开放七码搜寻、分析和已探索节点寻路；其余能力保持锁定。

## 场景和数据

- 场景状态统一S0—S6。
- 正式状态ID不得显示在玩家UI中。
- MECH-001—047、UI-001—083不得重编号。
- G01教学机制使用TUT-MECH-001—003。
- G01危险使用DANGER-G01-001—004。
- 场景、热点、HOS、背包、对白、提示、存档、变量和资产映射必须数据驱动。

```text
g01_chapter_complete=true
g01_handoff_to_g02=true

```

旧存档载入后也必须强制星核数为0。
