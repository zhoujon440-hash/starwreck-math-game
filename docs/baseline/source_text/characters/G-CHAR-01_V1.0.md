主角“星宇”造型基线

C方案：布偶机械坠落幸存者 · 一致性修正版

| 文件编号 | G-CHAR-01 | 版本 | V1.0 |
| --- | --- | --- | --- |
| 阶段 | S2概念设计修订 | 工程状态 | Unity未启动 |

| 唯一有效方向：星宇不是写实人类少年，而是视觉年龄13—15岁的布偶机械少年。采用C“坠落幸存者”叙事与服装结构，保留项目原有毛毡、缝线、纽扣与电子废料视觉基因。 |
| --- |

# 一、角色定位

| 维度 | 正式设定 |
| --- | --- |
| 身份 | 银河遗弃带中的布偶机械生命体；文明修复者候选体；“拾光号”坠落后的探索者。 |
| 视觉年龄 | 13—15岁，不幼态、不成人硬汉化。 |
| 性格 | 行动快、敢承担风险；遇到证据后会修正判断；愿意观察、尝试和重新开始。 |
| 画面功能 | 在图片解密场景中承担视线引导、工具操作、状态反馈和剧情情绪。 |

# 二、造型结构

| 部位 | 设计要求 | 图片解密中的用途 |
| --- | --- | --- |
| 身体 | 灰蓝旧毛毡，手臂/颈部保留可见缝线；局部棉絮或机械接口可见 | 一眼确认布偶生命体；近景可作为线索 |
| 头部 | 短毛线头发；一只黑色纽扣眼、一只青绿电子镜片眼 | 电子眼负责扫描/放大/聚焦反馈 |
| 上身 | 拆解飞行服＋旧帆布短斗篷/披片；外露绑带与一处新修补补丁 | 体现坠落幸存者与成长阶段 |
| 肩部 | 键盘按键护肩或旧控制板碎片，不对称 | 保持废料来源与剪影识别 |
| 腰背 | 工具腰带＋窄型废铁背包；可挂七码接口或图纸筒 | 承载交互道具与资源记录 |
| 腿足 | 左右不对称：旧运动鞋＋机械防护靴；局部绑带 | 避免标准人类制服感 |
| 识别色 | 氧化橙为主；青蓝只用于电子眼/能源状态 | 成熟、克制、功能可读 |

# 三、装备阶段

| 阶段 | 外观 | 限制 |
| --- | --- | --- |
| 开场坠落 | 基础工具腰带、扫描眼、残损飞行服、临时绑带 | 尚无完整磁力手套；避免“开局满配” |
| 工坊修复后 | 获得/修复磁力手套，能源槽结构可见 | 仍保留旧件和补丁，不换成全新装备 |
| 短距瞬移解锁 | 腰侧/腿侧折叠环形模块，触发青蓝短轨迹 | 不做背部大型喷射器 |
| 终局前 | 三能源槽、授权标识和临时稳定扣具出现 | 升级是增加部件，不替换原造型 |

# 五、轻动效记忆点

待机：身体每2—3秒轻微上下1—2像素，斗篷边缘延迟摆动。

思考：电子镜片眼短促放大，扫描纹理由外向内收束。

紧张：手指/夹具轻拧工具腰带，背包小零件轻响。

成功：小扳手上抛可保留为1个短序列帧，不做完整骨骼动作。

受冲击：布偶身体压扁—回弹可用3—5帧变形序列或Sprite替换。

# 六、禁用项

写实人类皮肤、普通真人少年脸、自然头发丝表现。

6.5—7头身写实人体作为硬性比例；布偶比例允许5.5—6.5头身并保留手工不对称。

标准科幻制服、军用重甲、末日佣兵、校园服装。

大眼萌系、幼儿动画、过度可爱表情。

正式资源阶段之前制作完整3D模型或全套骨骼动作。
