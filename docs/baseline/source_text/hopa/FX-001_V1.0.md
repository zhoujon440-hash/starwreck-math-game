# 一、角色与造型基线

| 维度 | 正式要求 |
| --- | --- |
| 角色 | 星宇；视觉年龄13—15岁；布偶机械少年；C方案坠落幸存者造型 |
| 材质 | 灰蓝旧毛毡、缝线、纽扣眼、青绿电子镜片眼、旧帆布斗篷、废铁背包 |
| 瞬移模块 | 腰侧/腿侧小型折叠环模块；不能改成背部喷射器或科幻战甲 |
| 识别色 | 氧化橙为结构色；青蓝仅用于电子眼、锚点与空间缝线 |
| 动画方式 | 姿态替换、局部变形、2—5帧短序列和场景层折叠；不要求完整骨骼动画 |

# 二、玩家使用流程

| 步骤 | 玩家行为 | 画面表现 | 系统条件 |
| --- | --- | --- | --- |
| 1 发现锚点 | 调查场景中的锚点A与B | 锚点由灰暗变为可识别状态 | Hotspot已调查 |
| 2 修复/授权 | 使用背包物或完成锚点小游戏 | 机械环恢复，显示三段复位刻度 | 锚点供电＋授权完成 |
| 3 选择能力 | 点击能力按钮或场景内角色快捷动作 | 合法锚点青蓝呼吸高亮，非法目标保持灰色 | 至少两个合法锚点 |
| 4 选择目标 | 点击目标锚点 | 起点与目标之间出现空间缝线预览 | 目标已发现且未封锁 |
| 5 启动瞬移 | 再次确认或直接点击 | 星宇触碰腰侧折叠环，人物层收束 | 未处于小游戏或对话锁定 |
| 6 折叠转场 | 无需额外操作 | 局部场景像布料折叠，缝线结点移动 | 0.6—0.9秒 |
| 7 到达与反馈 | 恢复观察和交互 | 目标锚点展开，星宇出现，旧位置残影消散 | 场景相机/观察位切换 |

# 三、视觉关键帧与时间轴

| 时间 | 关键帧 | 角色层 | 特效层 | 场景/交互层 |
| --- | --- | --- | --- | --- |
| 0.00s | 待机 | 原确认姿态 | 锚点低亮 | 玩家可观察场景 |
| 0.10s | 触发 | 右手触碰瞬移模块，电子眼聚焦 | 模块三段刻度点亮 | 合法目标高亮 |
| 0.25s | 收束 | 身体轮廓轻压缩为缝线结点 | 起点锚点拉出缝线 | 其他热点暂时降低亮度 |
| 0.45s | 折叠 | 人物主体隐藏，仅保留小结点 | 空间缝线沿合法路径滑动 | 只折叠局部世界层，UI稳定 |
| 0.70s | 展开 | 目标处由结点恢复角色姿态 | 目标锚点扩散一圈青蓝波纹 | 观察位置切换 |
| 0.90s | 完成 | 恢复待机/操作姿态 | 旧位置残影2—3帧消失 | 所有热点恢复正常 |

# 四、失败、中断与回退

| 异常 | 表现 | 回退结果 | 玩家提示 |
| --- | --- | --- | --- |
| 锚点未发现 | 不高亮、不可点击 | 能力不启动 | 提示先调查区域 |
| 锚点未供电 | 缝线预览到锚点前断开 | 星宇保持原位 | 提示需要修复供电 |
| 剧情封锁 | 锚点出现锁定缝线标记 | 保持原位，不消耗状态 | 提示剧情原因或缺失物品 |
| 中途触发对话/剧情 | 瞬移启动前取消 | 不改变场景状态 | 对话结束后可重新选择 |
| 资源或状态异常 | 模块橙色警示，锚点不响应 | 不丢背包和解谜进度 | 提供可恢复条件 |

# 五、冷却与提示机制

瞬移后锚点机械环进行2—3秒复位；这是视觉节奏，不是战斗式惩罚冷却。

复位期间玩家仍可观察场景、查看背包、地图、日记和证据板。

复位由锚点三段刻度依次点亮表示，不设置悬浮的长进度条。

玩家停滞时，提示系统可高亮合法锚点；三级提示可以直接显示应选择的目标。

连续双锚点小游戏可用机关自身节拍替代冷却，并允许跳过小游戏但不跳过剧情结果。

# 六、美术与程序拆层清单

| 资源层 | 数量建议 | 内容 | 技术要求 |
| --- | --- | --- | --- |
| 星宇姿态层 | 3—4张 | 待机、触发、收束、到达 | 与已确认人物母版一致，透明PNG |
| 瞬移模块层 | 3状态 | 关闭、启动、复位 | 绑定腰侧/腿侧，不改变主体造型 |
| 起点锚点层 | 4状态 | 未发现、可用、启动、复位 | 支持场景状态替换 |
| 目标锚点层 | 4状态 | 未发现、可选、到达、复位 | 支持合法/非法目标编码 |
| 空间缝线层 | 4—6帧 | 预览、连接、滑动、断裂 | 透明通道；不遮挡线索文本 |
| 人物残影层 | 2—3帧 | 旧位置消散 | 低透明、无高频闪烁 |
| 落点反馈层 | 2—4帧 | 展开波纹、地面线条 | 作用范围小于角色高度 |
| UI提示层 | 3状态 | 合法、锁定、提示目标 | 固定屏幕层，不随场景抖动 |

# 七、低性能与无障碍版本

| 模式 | 调整 |
| --- | --- |
| 低性能 | 关闭布料折叠变形，只保留角色淡出/淡入、直线缝线和锚点波纹 |
| 减少动效 | 空间缝线从4—6帧缩为2帧，残影关闭，复位刻度保留 |
| 色弱辅助 | 合法目标使用青蓝＋圆环；锁定目标使用橙色＋锁形；不可只靠颜色 |
| 闪烁安全 | 禁止全屏闪白；亮度变化控制在局部锚点和角色轮廓 |
| 提示文本 | 能力不可用时给出具体原因，不只显示“失败” |
