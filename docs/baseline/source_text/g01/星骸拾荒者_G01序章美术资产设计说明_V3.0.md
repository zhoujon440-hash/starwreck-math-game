《星骸拾荒者》G01序章美术资产设计说明 V3.0

# 一、视觉边界

G01不重设计星宇、七码和拾光号造型，沿用已冻结C方案、旧档案、手工布偶与维修机械风格。新增资产用于补齐序章场景状态、专用道具、轻动效、环境危险和教学机制构图。

# 二、新增资产统计

场景：8项。

道具：12项。

效果：6项。

危险视觉：4项。

教学机制视觉：3项。

# 三、场景状态要求

维修舱：断电红光/恢复暖光。

导航核心舱：七码离线/上线。

货舱：漏气霜雾/复压清晰。

星图室：碎片缺口/十二环点亮。

航线驾驶舱：垃圾雨预警/安全窗口。

落点交接：近地扫描/舱门开启。

# 四、Unity切图建议

每个场景至少拆分背景、前景遮挡、热点物、状态替换物、轻动效层和危险预警层；1920×1080基准，保留16:9安全区。道具提供背包图标、场景小图和安装后状态。
