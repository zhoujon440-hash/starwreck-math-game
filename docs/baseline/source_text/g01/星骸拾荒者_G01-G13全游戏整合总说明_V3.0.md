《星骸拾荒者》G01—G13全游戏整合总说明 V3.0

# 一、整合结论

G01《拾光号：坠落之前》已正式加入全游戏，补齐剧情、HOPA实施脚本、美术资产、Unity数据、存档变量和G02交接。完整游戏现由1个序章＋12个星球章节构成。

# 二、G01新增内容

剧情/HOPA脚本1份

Unity主工作簿1份＋10类CSV/JSON

8个序章场景

12个专用道具

6个轻动效

4个环境危险视觉

3个教学机制视觉

3张美术概念总览板

# 三、保留的冻结编号

MECH-001—047、UI-001—083、G02—G13章节编号和十二星核逻辑保持不变。G01教学机制使用TUT-MECH-001—003，危险使用DANGER-G01独立编号。

# 四、G02边界修订

G02不再承担星宇登场、七码恢复、基础教学和完整垃圾雨航线。SCN-G02-00仅保留落点交接，随后进入阿铆救援与资源归属冲突。

# 五、美术总量

原七大资产合计455项；G01新增33项后，V3.0总计488项。其中正式机制47项和正式UI83项不变，另设3项G01教学机制视觉。

# 六、Unity入口规则

新游戏固定从G01开始。

旧存档可通过兼容迁移直接进入G02，并补写G01基础能力变量。

G01结束world_star_core_count保持0。

G02前置条件为g01_chapter_complete与g01_handoff_to_g02。

G13结局仍读取十二星球星核，不把G01计入星核。
