# 二、发现的角色设定冲突

| 对比项 | 原始世界观设定 | 当前概念稿 | 判定 |
| --- | --- | --- | --- |
| 生命形态 | 布偶机械生命体：毛毡、缝线、纽扣眼、电子镜片眼 | 写实人类少年：短发、维修服、6.5—7头身 | 冲突 |
| 人物年龄表达 | 原稿约10岁；后续项目已升级为六年级至初中、成熟表达 | 视觉年龄14—15岁 | 年龄升级合理，但不能自动改变生命形态 |
| 美术语言 | 手工布偶＋未来科技＋电子废土；定格动画质感 | 风格化半写实人类科幻 | 偏离项目视觉基因 |
| 装备来源 | 键盘护肩、工具腰带、废铁背包、异构鞋靴 | 通用科幻维修服与设备 | 需要恢复废料来源可读性 |

一致性判定：主角更名为“星宇”和受众年龄升级，只改变名称、叙事成熟度与视觉年龄，不等于把主角从布偶生命体改成人类。当前人类少年概念属于未授权的设定漂移，应予修正。

# 三、修正后的星宇唯一有效基线

身份：视觉年龄约13—15岁的布偶机械少年／文明修复者候选体，不是真实人类。

人物方向：C“坠落幸存者”。保留拆解飞行服、自制绑带、外露接口、临时防护件和明显修补痕迹。

核心材质：灰蓝旧毛毡身体、可见缝线、一只黑色纽扣眼＋一只青绿色电子镜片眼。

标志部件：键盘按键护肩、工具腰带、废铁窄背包、左右不对称鞋靴、氧化橙识别色。

功能装备：磁力手套和短距瞬移装置作为后续获得/升级部件；初始状态不得表现为全套成熟装备。

性格：行动快、敢承担风险，但会根据证据修正判断；不是鲁莽英雄，也不是天才救世主。

造型禁用：写实人类皮肤、普通人类头发、军武重甲、校园制服、萌系大眼、成人末日硬汉。
