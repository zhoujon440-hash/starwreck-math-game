# 二、变更控制

视觉母版确认前，只允许做概念探索，不批量生产正式模型。

角色年龄感不得低于13岁，也不得呈现成年化、性感化或军武化。

锈环星的“旧”和“破”必须体现可维修、可理解、有人使用过，不能变成纯末日废墟。

UI需体现数据关系和因果，不使用儿童贴纸式奖励，也不模拟真实考试卷。

任何概念图只作为设计输入，正式资产需在灰盒验证后再生产。
