# 二、不可突破的设计原则

磁力手套的失败必须能解释为极性、峰值、持续供能、线路损耗或过热参数问题，不使用随机故障。

豆包拥有完整决定权。玩家只能展示数据、说明用途并提出请求，不能把“同意”做成唯一正确按钮。

豆包拒绝或只提供较少能源时，主线仍可通过低功率校准和延时蓄能继续，代价是后续操作更紧张，而不是死档。

五座塔不是五道孤立算术题，而是狰的五类清算权限：登记、配平、传输、稳定、授权。

所有数学模型必须由世界内仪表、日志、线路和装置状态支撑；默认不弹独立练习题面板。

每个危险段采用局部检查点；模型证据一经取得永久保留。
