# 二、设计原则

四条路线不以推荐箭头规定唯一顺序；玩家可以标记路线并随时回工坊。

三种能源分别解决峰值、稳定供能和低损耗传输，任何一种都不能替代另外两种。

第四条“供暖棚”支路不提供可直接拆走的能源核心，而是验证公共资源保护、替代供暖和有限借用。

数学关系通过仪表、结构、声音、线路和角色反应呈现；默认不弹独立答题界面。

每条支路至少存在一种可行解；关键节点优先允许多解和代价差异。

失败只重置当地操作段，已取得证据和已完成支路快照保留。
