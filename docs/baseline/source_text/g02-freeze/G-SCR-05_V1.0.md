# 二、不可突破的设计原则

Boss不是传统血条战。玩家通过已取得的证据、配置和角色协作，逐项解除登记、配平、传输、稳定和授权五类清算权限。

B0—B5只迁移前四册已经学习和预演过的规则，不在终局新增隐藏公式、新资源或必须猜测的唯一答案。

B6规则时长固定为12.00秒，玩家全程可操作；纯影片、自动QTE、Timeline完成信号均不得代替游戏状态机。

豆包的同意、部分同意或拒绝只改变能源缓冲、提示宽容和少量对白；三条路线均可获得完整主结局，不显示道德评分。

失败只回到当前Boss检查点，B0—B5已提交权限和永久证据保留；玩家在15秒内重新获得控制。

狰的错误规则被修正，但角色不被摧毁。通关强调“让系统看见借、用、还的过程”，而不是打败一个坏人。

学习结算不做百分制、排名或考试报告；用世界证据、能力档案和可回看的关键关系展示玩家完成了什么。

结算必须包含可见世界改变、借用资源归还和下一星球紧急事件，不能只弹奖励窗口。
