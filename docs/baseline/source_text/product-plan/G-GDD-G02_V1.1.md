# 一、首发定位

| 控制项 | 正式结论 |
| --- | --- |
| 星球 | G02《锈环星》 |
| 首发目标 | 验证成熟科幻探索、角色伦理与数学系统能在同一完整星球中成立 |

| 产品表达 | 沿用15—18岁产品基线，不低幼化 |

| 工程状态 | 未启动 |

# 二、故事与核心问题

| 锈环星正在被管理员“狰”的清算规则逐步封存。所有未被正确登记、无法证明归属或被判断为低效的资源都会被五条尾索收走。玩家必须在垃圾雨和能源崩溃前，理解资源的来源、用途、借用与归还关系，修复磁力手套，组织居民自愿贡献的能源，并在十二秒稳定窗口内解除五项清算权限。 |
| --- |

本星球的核心不是“找到五块电池”，而是回答：当系统只能计算资源，却无法计算承诺、生命和归还时，玩家怎样用可验证的规则让系统重新允许修复。

# 三、体验支柱

| 支柱 | 玩家体验 | 设计约束 |
| --- | --- | --- |
| 观察 | 环境细节、声音、旧记录和物品痕迹都能提供线索 | 不得依赖任务箭头代替调查 |
| 资源责任 | 物品有归属、用途、损耗和归还状态 | 关键角色不能被视作无主资源 |
| 工具成长 | 磁力手套从临时试装到有履历的长期装备 | 能力来自材料、调试和失误，不来自技能点购买 |
| 数学行动 | 持续判断还差多少、怎样配比、如何降低损耗和维持稳定 | 不出现脱离世界的练习题界面 |
| 可恢复危险 | 追逐、坍塌、电流、过热和尾索造成压力 | 失败必须快速回到决策点 |
| 非血量Boss | 通过五路供能和权限解除改变系统规则 | 不得用攻击数值替代推理和协作 |

# 四、整体流程与地点职责

| 地点 | 产品职责 | 主要事件 | 数学职责 | 制作阶段 |
| --- | --- | --- | --- | --- |
| L00 | 坠落/垃圾雨入口 | 建立异常、基础扫描与安全移动 | 估算、方向、相对位置 | M1首个可玩 |
| L01 | 旧屏幕谷/安全棚 | 救援居民、认识豆包和阿铆、恢复旧记录 | 分类、数据读取、归属证据 | M2核心 |
| L02 | 阿铆工坊 | 交易、维修、组合与磁力手套准备 | 单价总价、库存、材料配比 | M2核心 |
| L03 | 发动机坑/吊臂区 | 载荷、双开关、微型电容接口 | 比例、承重、同步时序 | M3 |
| L04 | 短路蜘蛛与电芯区 | 观察周期、取得稳定芯、断开错误桥接 | 周期、阈值、逻辑排除 | M3 |
| L05 | 供暖棚/旧键盘区 | 公共核心、替代供暖和借用边界 | 百分数、剩余量、资源约束 | M3 |
| L06 | 电线森林 | 根据烧痕与电流声选择安全线路 | 路径、损耗、图形与逻辑 | M4 |
| L07 | 手套校准区 | 复制体同步保持、极性和过热校准 | 等量关系、参数诊断 | M4 |
| L08 | 豆包借电事件 | 确认主/备用电区与自主决定权 | 百分数、风险、条件判断 | M4关键剧情 |
| L09 | 五塔能源平台 | 多路供能、线路损耗和阶段快照 | 方程、比例、图表、优化 | M5 |
| L10 | 星门核心/Boss | 解除五项权限并维持十二秒回路 | 综合建模、调度、时序迁移 | M5终局 |

# 五、主线任务链

| 任务 | 完成目标 | 叙事价值 | 系统/数学 |
| --- | --- | --- | --- |
| M01 垃圾雨前的蓝光 | 扫描三处异常并安全降落 | 让玩家先观察再行动 | 基础扫描、移动、风险反馈 |
| M02 五条尾巴正在收走一切 | 救下居民并追踪一条尾索 | 建立危机与狰的规则 | 追逐、检查点、路线选择 |
| M03 谁说这是无主之物 | 修复电视墙并读取归属记录 | 把“资源归属”变为可操作规则 | 证据链、分类与档案 |
| M04 三种不能替代的能源 | 取得关键材料并保证供暖不断 | 建立资源不可随意替代 | 配比、损耗、公共资源保护 |
| M05 这只手套脾气很坏 | 完成磁力手套试装并控制过热 | 工具成长和可恢复失败 | 参数、阈值、组合 |
| M06 豆包不是第五块电池 | 确认主电池与备用电区，征得借用同意 | 角色自主权与数学后果结合 | 剩余量、风险与条件判断 |
| M07 五座塔为何永远不够 | 调查五塔权限、输入与损耗 | 为Boss建立完整证据和数值模型 | 方程、图表、优化 |
| M08 十二秒不是一个人的电 | 完成供能、解除权限、维持稳定窗口 | 汇总全关技能、关系和数学迁移 | 综合多任务Boss |

# 六、角色可玩职能

| 角色 | 本关成长 | 可玩职责 | 禁止处理 |
| --- | --- | --- | --- |
| 星宇 | 从先冲出去到先询问资源与同伴意愿 | 移动、瞬移、缩小、复制体、组合工具、危险站位 | 不能替NPC决定借出生命资源 |
| 七码 | 错误可笑但必须可恢复；提问成为破局入口 | 背包、搜寻、分析、寻路、记录与提示 | 不能直接公布答案或随机破坏正确数据 |
| 豆包 | 从被当作“第五块电池”到主动决定备用电用途 | 提供角色选择、能源边界和Boss协作 | 不得成为可拆卸关键道具 |
| 阿铆 | 从资源焦虑到接受登记、借用和归还 | 工坊、维修、组合、经济保护线 | 不得承担万能补给或无代价修复 |
| 狰 | 从只计算资源效率到更新对修复与承诺的判断 | 五尾危险、权限控制、非血量Boss | 不转为传统反派血条 |

# 七、数学任务与叙事融合

| 阶段 | 数学问题 | 叙事问题 | 玩家必须做的事 |
| --- | --- | --- | --- |
| 入口 | 哪个落点风险更低？ | 是否先观察还是直接冲入垃圾雨？ | 比较信号、方向和落点 |
| 资源调查 | 三类能源为什么不能直接替代？ | 公共供暖能否被拆走？ | 比较容量、用途、损耗和归属 |
| 装备调试 | 磁力、极性、温度如何稳定？ | 工具为什么会坏、谁承担修复？ | 调参并观察阈值 |
| 豆包事件 | 借出备用电后还剩多少安全余量？ | 角色是否有决定权？ | 读取电区、评估后果、征得同意 |
| 五塔模型 | 怎样让五路输入满足不同权限条件？ | 狰的规则哪里错误？ | 建立关系、配平、降低损耗 |
| Boss | 十二秒中怎样并行维持全部约束？ | 胜利是否来自一个人牺牲？ | 调度角色、资源、技能和时序 |

# 十、首发验收标准

玩家能在不依赖答案式提示的情况下完成至少一条基础路线。

玩家能复述锈环星危机、狰的判断逻辑、豆包为何不是资源以及最终解决方式。

前段出现的比例/损耗/参数关系能在五塔或Boss阶段再次使用。

任何交易、组合、借用、失败和退出路径都不会造成永久死档。

危险失败后15秒内恢复控制；已看长演出可跳过且状态一致。

通关后居民、设施、环境音、路线和星门状态出现可见变化。

标准PC离线运行、存档可恢复、日志可定位问题。
