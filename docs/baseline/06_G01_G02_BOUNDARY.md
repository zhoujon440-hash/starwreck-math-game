# G01→G02章节边界

## G01职责

G01负责：

- 星宇首次正式登场；
- 七码失联、修复和恢复；
- 拾光号关系建立；
- 点击、拾取、HOS、背包拖拽、局部机关教学；
- 货舱危险、软失败和安全恢复教学；
- 星图缺口和十二星门异常首次出现；
- 锈环星求救信号；
- 七码搜寻、分析和已探索节点寻路授权；
- 扫描旧屏幕谷外缘并坠落交接G02。

G01不获得星核，不开放瞬移、缩小和复制体。

## G02开场

G02从“旧屏幕谷外缘交接”开始，直接承接G01坠落结果。

G02不得重复：

- 主角基础身份介绍；
- 七码恢复；
- 基础HOPA点击、拾取和背包教学；
- 完整垃圾雨航线；
- 基础能力授权说明。

G02应立即进入：

- 坠落后的现场判断；
- 求救对象与锈环星危机；
- 已开放搜寻/分析/寻路的实际应用；
- 锈环星第一条正式任务链。

## 交接变量

G01结束：

```text
g01_chapter_complete=true
g01_handoff_to_g02=true
world_star_core_count=0
qima_recovered=true
```

G02开场应读取以上变量，并拒绝缺少G01交接的异常存档或执行迁移。

## 资产与ID边界

- G01使用TUT-MECH-001—003、DANGER-G01-001—004和G01专用新增美术；
- G02使用MECH-001—003、DANGER-001—006、UI-013—015及UI-060—061；
- 不得把G01教学ID占用为G02正式机制ID；
- G02不得重新编号既有MECH/DANGER/UI资产。

## 验收

完成G01后，玩家应理解基本HOPA操作和星宇/七码关系；进入G02时应感到剧情连续，而不是重新开始一款游戏。
