## SCN-G01-01《找回七码》

运行时按独立场景定义加载，不与 SCN-G01-00 的 S0—S6、热点或物品混用。

1. S0：星宇进入导航核心舱，追踪微弱信号。
2. S1：检查托架，确认七码处于 `offline`。
3. S2：确认受损，七码进入 `damaged`；打开 `HOS-G01-002`。
4. HOS：在真实场景裁切中找回七码芯片、接线片、保险丝和固定扣；六件干扰物保留。
5. S3：局部放大七码芯片，完成方向校正小游戏。
6. S4：依次拖拽接线片、保险丝、芯片、固定扣完成维修。
7. 错误使用：接口反馈但道具不消耗、已完成步骤不回滚、状态不前进。
8. S5：七码进入 `booting`，3.2 秒启动校验没有跳过按钮。
9. S6：七码先显示 `normal`，再播放正式首次对白 `DLG-G01-0004`—`0006`。
10. 对话结束后解锁七码档案和两条恢复发现信息。

七码的必经迁移为：

`offline → damaged → booting → normal`
