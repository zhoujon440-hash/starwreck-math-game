# G01首轮数据基线

## SCN-G01-00 拾光号熄灯

### 目标
恢复应急照明。

### 必要对象
- HS-G01-0001 应急手灯
- HS-G01-0002 熔断配电盒
- HS-G01-0003 维修柜
- HS-G01-0004 应急照明槽

### 找物
HOS-G01-001 维修柜找物：
- 临时保险丝（关键）
- 旧扳手
- 绝缘手套
- 线号标签
- 干扰物：烧毁保险丝、普通螺丝

### 道具链
应急手灯→调查配电盒→打开维修柜→找到临时保险丝→保险丝进入背包→用于应急照明槽→照明恢复。

### 场景状态
- S0：断电红光，配电盒不可清晰调查。
- S1：取得手灯，配电盒可调查。
- S2：维修柜打开，找物完成。
- S3：选择/拖拽保险丝。
- S4：短路危险解除。
- S5：照明恢复，开放下一场景。

### 对话
- 星宇：七码？回答。
- 系统：导航核心离线。维修舱进入应急照明模式。
- 星宇：先找光，再找故障。

### 防卡死
- 临时保险丝错误使用不消耗。
- 找物完成后重进不刷新关键物。
- 读档后维修柜、保险丝、照明和背包状态一致。
