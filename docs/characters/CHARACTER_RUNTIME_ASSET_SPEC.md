# 星宇与七码运行时角色资产规格

范围：Issue #8，仅制作星宇 5 状态与七码 9 状态的透明运行时切片。本批资产不接入剧情、对白系统或 `SCN-G01-01`。

## 冻结来源

- 正式包：`PKG-CHARACTERS-V2.1`
- 包内母版：`星骸拾荒者_人物形象设计全集_V2.1_补齐版/01_十二星球人物三视图/G02_锈环星_人物三视图.png`
- 母版 SHA-256：`c549fe94157daea3606a1b7b32562e28108c9e54f2dac1b156b38c8097c0a0b3`
- 星宇补充依据：`G-CHAR-01 V1.0`、`G-S2-CHG-01 V1.0`
- 共同视觉依据：`G-S2-D01 V1.0` 未被替代条款、`G-ANIM-01 V1.0`

## 输出

所有正式文件均为 2048×2048 RGBA PNG，带真实透明像素和安全留白。

- 星宇：`normal`、`alert`、`thinking`、`nervous`、`determined`
- 七码：`offline`、`damaged`、`booting`、`normal`、`question`、`warning`、`proud`、`awkward`、`scanning`

星宇保持纽扣眼、青蓝电子镜片眼、灰白毛毡短发、氧化橙围领、修复者工具与非军武轮廓。七码保持 EDU-0077 身份、旧 CRT 头部、双天线、短机械臂、轮足和奶黄/旧铜/氧化橙材质。

## 制作方法

1. 读取正式 ZIP 并校验包与母版条目 SHA-256。
2. 从 G02 三视图板定位正面母版，不复用 PR #5 资产。
3. 使用经人工核对的轮廓遮罩与保守纸张泛洪清理标题、辅助线、设计板背景及相邻格。
4. 使用预乘 alpha 的 Lanczos 放大到 2048 画布，避免深浅背景边缘污染。
5. 星宇仅局部调整嘴形、电子眼光强和小于 1° 的姿态偏移。
6. 七码仅替换 CRT 像素表情、轻微受损线和小于 1° 的姿态偏移；扫描线为独立图层。

未调用生成式图像服务，未整体重绘人物，也未改变比例、服装、主色、装备或头部结构。

## 轻动效层

- 星宇：`electronic_eye_glow`
- 七码：`crt_screen_normal`、`scan_effect`

这些图层只支持眼部/屏幕反馈、天线轻摆和扫描，不建立战斗骨骼、跑跳、自由移动或攻击状态机。
