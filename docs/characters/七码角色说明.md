# 七码角色说明

- 名称：七码
- 编号：EDU-0077
- 类型：拾光号搭档机器人
- 功能：扫描、记录与维修协作
- 首次出场：SCN-G01-01《找回七码》
- 性格：精确、较真，习惯用冷静记录制造机械幽默

## 冻结视觉

七码保留旧显示屏头部、奶黄色修补机身、像素表情和明显维修痕迹，不使用普通人形比例。
运行时提供 `offline`、`damaged`、`booting`、`normal`、`question`、`warning`、`proud`、
`awkward`、`scanning` 九种透明状态。

## 正式出场

七码在开场保持失联，不能提前解锁。玩家恢复应急照明并进入导航核心舱后，依次调查损坏机体、
找齐部件、完成顺序维修和线路校准，视觉状态按
`offline → damaged → booting → normal` 改变。恢复时写入：

- `character_profile_qima_unlocked = true`
- `qima_recovered = true`

角色介绍确认后才进入星宇与七码的第一段完整互动；档案和介绍状态会随存档恢复，不重复弹出。
