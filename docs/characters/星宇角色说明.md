# 星宇角色说明

- 姓名：星宇
- 身份：拾光号上的少年修复者
- 首次出场：SCN-G01-00《拾光号熄灯》
- 当前目标：恢复拾光号并寻找失联的七码
- 性格：遇到故障先观察再行动，对飞船和搭档抱有强烈责任感

## 运行时视觉

运行时提供 `normal`、`alert`、`thinking`、`nervous`、`determined` 五种透明半身立绘，
固定在对话左侧。首次开场对白解锁角色档案并出现一次简短介绍卡。

仓库没有星宇冻结人物设计板。本轮形象只依据已冻结的“拾光号少年修复者”身份、12—18 岁
产品气质和现有飞船美术建立保守运行时版本；发型、服装制式与个人标志待项目负责人补充。

资产来源、处理方式和完整生成提示词见 `art/README.md` 与
`art/prompts/g01-character-story-v1.md`。
