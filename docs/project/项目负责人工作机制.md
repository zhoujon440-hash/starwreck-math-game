# 项目负责人工作机制

## 角色

- ChatGPT：项目负责人，负责需求冻结、任务拆分、开发节奏、PR审查、视觉验收、缺陷分级和阶段准入。
- Codex：开发执行，负责代码、测试、构建、截图、文档和PR修复。

## 流程

1. 项目负责人在仓库创建任务与验收门。
2. Codex在独立分支开发并提交PR。
3. 项目负责人检查：
   - 需求符合性；
   - HOPA交互是否真实；
   - 视觉是否仍有占位原型问题；
   - 测试、构建和存档是否通过；
   - 是否违反冻结规则。
4. 不通过则在PR中提出修改项。
5. 通过后才允许进入下一场景或下一章。

## 阶段顺序

- P1：工程骨架与SCN-G01-00。
- P2：SCN-G01-01至03。
- P3：SCN-G01-04至07与两个小游戏。
- P4：G01整章通关、存档、PWA、视觉统一。
- P5：G02锈环星。

Codex不得跳过项目负责人的验收门自行推进G02。
