# Legacy 隔离区

本目录保存被替代、被否定、损坏或只可作历史参考的资料。这里的内容不得覆盖
`docs/baseline/`、`docs/story/G01-G13/`或`data/source/`的正式事实源。

- `corrupt/`：无法完整读取的旧Codex基线包；
- `originals/`：被否定的纯色HTML5原型和旧Unity当前工程路线原包；
- `manifest.json`：已隔离或已登记legacy资料的版本、SHA和替代关系。

历史文件中的“小砾”、Boss、战斗、血量、攻击、伤害、敌人AI和写实人类少年
星宇方案都只按legacy理解，不允许进入正式执行层。
