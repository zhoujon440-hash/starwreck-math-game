# 星骸拾荒者：十二星门

《星骸拾荒者：十二星门》是面向六年级至初中阶段、保持 15–18 岁产品气质的 HTML5 / PWA 互动式图像解谜与冒险游戏（HOPA）。

当前版本完成序章 G01《拾光号坠落之前》的第一场景：玩家以星宇的视角调查受损的拾光号领航舱，通过找物、背包道具使用、局部放大和电路谜题推进到 S6 安全节点。

## 冻结基线

- 主角固定为“星宇”。
- G01 是序章，不计入十二星门主星核数量。
- G02–G13 对应十二颗主星球。
- 产品是固定镜头的 HOPA，不包含自由移动、战斗、回合制或平台跳跃。
- 正式场景不显示圆点热点，不使用按钮列表代替场景探索。
- 当前技术方案固定为 HTML5 / PWA，不采用 Unity。
- 远程仓库初始化时为空；现有冻结脚本、人物、场景与道具资料未出现在仓库中。本版本只补充第一场景所需的最小叙事内容，后续导入冻结资料时以冻结资料为准。

## 运行

要求 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

常用检查：

```bash
npm test
npm run build
npm run preview
```

## 第一场景玩法

1. 在 S0 接管拾光号应急权限。
2. 在 S1 的手绘领航舱中找到绝缘扳手、记忆棱晶和星位罗盘。
3. 在 S2 把绝缘扳手拖到右下方检修舱。
4. 在 S3 放大检修舱，按照光谱线索完成应急电路。
5. 在 S4 把记忆棱晶拖到中央环形读取槽。
6. 在 S5 把星位罗盘拖到右侧领航盘。
7. 到达 S6，完成第一场景并写入安全存档。

触屏设备可先点选背包道具，再点击目标；也可直接长按拖拽。提示只短暂扫描目标区域，不会把正式场景变成圆点热点图。

## 存档

存档使用浏览器 `localStorage`，键名按章节和结构版本隔离：

- `starwreck:save:G01:v1`
- `starwreck:checkpoint:G01:v1`

普通操作自动保存。S0、S2、S4、S6 是安全节点；谜题失败可回退到最近安全节点。
